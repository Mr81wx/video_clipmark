# ClipMark 视频标签剪辑台

一个轻量、完全本地运行的视频标记网页工具。导入视频后，可以在关键时间点添加标签，并通过标签或时间轴标记快速回放。

## 功能

- 从电脑导入常见视频文件
- 播放、暂停、静音与拖动播放进度
- 在当前播放时间创建文字标签
- 标签自动保存到浏览器本地
- 下次导入同一个视频时自动读取已保存标签
- 点击“保存”后保存当前视频和所有标签
- 点击“保存到本地”后导出视频和标签文件
- 下次打开页面时自动读取最近保存的视频
- 显示最近打开/保存过的项目列表
- 点击右侧标签立即跳转并自动播放
- 在时间轴上显示每个标签的位置
- 删除不需要的标签
- 适配电脑和手机浏览器

## 使用方法

1. 用浏览器打开 `index.html`。
2. 点击“导入视频”，选择电脑上的视频文件。
3. 播放或拖动到需要记录的位置。
4. 在右侧输入标签内容并点击“添加”。
5. 点击标签卡片或时间轴上的竖线，即可回放对应片段。
6. 点击顶部“保存”，保存当前视频和标签到浏览器本地数据库。
7. 点击“保存到本地”，把视频文件和 `.clipmark.json` 标签文件保存到电脑。
8. 关闭页面后再次打开，会自动读取最近保存的视频和标签。
9. 在“最近项目”中点击项目，可恢复已保存的视频；未保存视频会提示重新导入。

## 保存说明

由于浏览器安全限制，普通网页不能直接把文件写入 `index.html` 所在文件夹。ClipMark 会把视频和标签保存到当前浏览器的本地数据库中，不需要服务器，也不会上传网络。

如果浏览器支持文件夹写入，“保存到本地”会让你选择一个文件夹，并在里面保存视频文件和同名 `.clipmark.json` 标签文件。如果浏览器不支持，会把这两个文件下载到默认下载位置。

“最近项目”会记录最近导入和保存过的视频。只有点击过“保存”的项目会保存视频本体，可以直接恢复；只导入过的视频会保留文件名和标签记录，需要重新选择原视频文件。

## 本地运行

项目不依赖构建工具或服务器，直接双击打开 `index.html` 即可使用。

如需通过本地服务器打开，可在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件结构

```text
index.html   页面结构
styles.css   视觉样式与响应式布局
app.js       视频播放、标签和时间轴逻辑
```

## 隐私

视频只在当前浏览器中读取、播放和保存，不会上传到网络或服务器。标签数据保存在当前浏览器的本地存储中，视频和项目数据保存在当前浏览器的本地数据库中。
